# Wanderwege

Android-App zur Auswahl und Erkundung von Wanderwegen. Das Projekt entstand im Rahmen meines Studiums. Routen können über eine Liste und eine Karte angesehen werden; außerdem wurden Funktionen für Kommentare und Bewertungen entwickelt.

Die Projektdokumentation und Präsentation befinden sich im Ordner `docs/`.

**Projektstand:** Dies ist der Stand des Hochschulprojekts. Die aktuelle Version ist nicht vollständig lauffähig und wird derzeit nicht aktiv weiterentwickelt.
